# F · Flower’s land 4

[题单与难度](../README.md) · [C++17 参考代码](../std/F.cpp) · 官方题面 PDF 第 10 页

## 题意与约束

已有线段连接 $`(x_i,0)`$ 与 $`(0,y_i)`$，坐标非负。查询线段连接 $`(a,0)`$ 与 $`(b,c)`$，判断是否和任意已有线段相交，端点接触算相交。所有测试的 $`n,q`$ 各自总和不超过 $`10^6`$，坐标不超过 $`10^9`$。

## 切入点：起点决定在直线哪侧

先考虑 $`x,y\gt 0`$ 的非退化线段，其直线方程为

```math
\frac{X}{x}+\frac{Y}{y}=1.
```

查询起点代入后得到 $`a/x-1`$，终点得到

```math
L=\frac b x+\frac c y-1.
```

查询线段处于第一象限，已有直线在第一象限的部分恰是已有线段，因此跨越这条直线就等价于线段相交。

- $`x=a`$：起点就在已有端点上，直接 `YES`。
- $`x\lt a`$：起点在正侧，需要 $`L\le0`$。
- $`x\gt a`$：起点在负侧，需要 $`L\ge0`$。

于是查询变成两类半平面条件下的线性函数极值。

## 双向扫描与倒数坐标凸包

把已有线段看成倒数坐标点

```math
P_i=(1/x_i,1/y_i).
```

需要在 $`x_i\lt a`$ 中求 $`bP_{i,x}+cP_{i,y}`$ 的最小值，以及在 $`x_i\gt a`$ 中求最大值。

1. 按 $`x`$ 从小到大扫已有点，按 $`a`$ 从小到大扫查询，维护已加入点的下凸包，查最小值。
2. 按 $`x`$ 从大到小扫已有点，反向扫查询，维护上凸包，查最大值。
3. 同 $`x`$ 的点只保留相应极值：最小查询保留最大 $`y`$；最大查询保留最小 $`y`$。
4. 加点横坐标单调，维护凸包只需栈。线性函数在凸链上单峰/单谷，用相邻点比较二分极值。

权重 $`b,c`$ 非负，所以这两条凸链足以回答目标方向的极值查询。

## 精确运算

不用真的算浮点倒数。比较两个倒数点 $`p,q`$ 的函数值时，正分母交叉相乘：

```math
\operatorname{sign}\left[\frac b{p_x}+\frac c{p_y}-\frac b{q_x}-\frac c{q_y}\right]
=
\operatorname{sign}\left[b(q_x-p_x)p_yq_y+c(q_y-p_y)p_xq_x\right].
```

凸包转向也交叉相乘，代码 `cross` 表示倒数点的真实转向符号。中间量可到 $`10^{36}`$ 量级，必须用 `__int128`，`long long` 不够。所有分母在该部分都严格为正。

## 坐标为 0 的退化情况

- $`y=0`$：已有线段在 x 轴上，是 `[0,x]`。若查询也在 x 轴上（$`c=0`$），相交当且仅当 $`\min(a,b)\le x`$；否则只可能在查询起点相交，条件为 $`a\le x`$。
- $`x=0,y\gt 0`$：已有线段在 y 轴上。若 $`a=0`$，起点就是原点，必相交；否则只有终点也在 y 轴且高度不超过 $`y`$ 才相交，即 $`b=0,c\le y`$。
- $`x=y=0`$：按 x 轴退化段处理即可。

所有水平段只需保留最大 $`x`$，所有垂直段只需保留最大 $`y`$。不要把 0 放入倒数点集合。

## 正确性与复杂度

相交判定已等价为端点在直线两侧或在线上；按 $`x`$ 分成的两类分别求最小值与最大值，只要存在满足条件的线段，其极值也满足条件，反之成立。扫描维护的集合精确满足严格大小关系，凸包保持所有可能提供目标极值的点。退化部分单独覆盖，所以算法完整。

时间 $`O((n+q)\log(n+q))`$，空间 $`O(n+q)`$。最大输入需注意排序、内存和读写常数。官方原题曾是线段连通块问题，本题是其分治中的子问题，见官方题解第 28–29 页。

## 可迁移总结

几何相交题先把点代入线性方程看符号，不一定需要维护线段本身。离线阈值约束 + 线性函数极值，常转成扫描线加凸包。本题的主要难点是倒数坐标精确比较与退化边界，适合作为赛后专题，不建议在临近区域赛时从零主攻。
