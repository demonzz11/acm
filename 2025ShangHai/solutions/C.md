# C · Singularity

[题单与难度](../README.md) · [C++17 参考代码](../std/C.cpp) · 官方题面 PDF 第 6–7 页

## 题意与约束

给定偶数长度排列，$`4\le n\le10^5`$，总长度不超过 $`2\cdot10^5`$。一次 `FakeSort(l,r)` 要求区间长度为偶数：分别把区间内最小的一半值、最大的一半值按它们各自原有位置排序，两类位置本身不交换。输出至多 114 次操作把排列排序，或输出 `-1`。

注意不是把两半连续区间各自排序。样例中的长度 6 排列可能无解，不能把大规模结论直接应用到所有 $`n`$。

## 切入点：把排列二值化

把 $`p_i\le n/2`$ 标为 0，其他标为 1。共有等量的 0、1。

如果把二值串排成全 0 接全 1，最后执行 `FakeSort(1,n)` 就能把两种值内部排序，整个排列有序。因此主要任务是改变二值位置。

为了让局部操作对二值串的作用可以精确模拟，每次局部操作前先执行一次全局 `FakeSort(1,n)`，保证所有 0 值内部、1 值内部都按位置递增。这个全局操作不改变二值模式。

## 精确模拟局部操作

设长度为 $`2h`$ 的区间有 $`z`$ 个 0。

- $`z\ge h`$：最靠前的 $`h`$ 个 0 对应区间最小一半，位置不变。其余 0 与全部 1 属于另一半，排序后在这些位置先填 $`z-h`$ 个 0，再填 1。
- $`z\lt h`$：最后 $`h`$ 个 1 属于最大一半，位置不变。全部 0 与最靠前的 $`h-z`$ 个 1 属于另一半，在这些位置先填 $`z`$ 个 0，再填 1。

因此每个局部操作用 $`O(n)`$ 扫描二值串即可，不需要真的对原排列反复调用排序。

## 子程序 Sort(l,r)

要求区间中 0、1 数量不等，长度为偶数。重复“全局操作 + 局部操作”：

- 0 多于 1：删除当前工作区间末尾已经有序的偶数个连续 1。
- 1 多于 0：删除开头已经有序的偶数个连续 0。

删除只是缩小接下来的工作区间，不改输出排列。**不能两端都删**，否则可能把非零数量差消成零，使后续操作不再推进。

如果数量差是 $`2k`$，局部排序把后 $`k`$ 个 0 向前移，或把前 $`k`$ 个 1 向后移。已固定边缘段随轮次扩大；下一轮若仍未有序，有效不平衡规模至少倍增，故 $`O(\log n)`$ 轮结束。每轮输出两次操作。

## 大规模构造

官方结论：$`n\ge8`$ 时，唯一无解的二值模式是严格交替的 `0101…` 或 `1010…`。任意偶长子段都恰有一半 0、一半 1，局部操作不改变模式，故这两类无法变成排序模式。

对其他模式，令前缀差为“0 数量减 1 数量”。

1. 找一个差为 $`\pm2`$、且至少含两个 0 的前缀。先 `Sort` 这个前缀，把两个 0 固定在全串最前面；再 `Sort(3,n)`。第二个区间少了两个 0，数量差非零，所以可以排序。
2. 若没有合适前缀，需要制造它。一般情况下取前缀差为 +1 和 -1 的最远一对位置，二者之间的区间差为 $`\pm2`$；先 `Sort` 这个区间，再重新寻找第 1 步的前缀。
3. 如果已有差为 -2 的前缀太短，不能直接当第 1 步使用。若开头就是两个 1，先 `Sort(3,n)`，其长后缀至少有两个 1，能固定全串末尾两个 1，再 `Sort(1,n-2)` 即可。若前四位只有一个 0，先排序这四位，把 +1 前缀制造出来，再按最远 +1/-1 对处理。

这些短前缀修复对应官方证明中“前缀必须至少含两个 0”的要求。代码没有使用官方题解里优化操作次数的另一种写法，而是保留了更直接的三个排序子程序与短区间修复。

一个辅助结构性质是：排除严格交替模式后，上述修复要么直接固定正确的两端元素，要么使最远 +1/-1 区间的排序制造出符合第 1 步的前缀。可以通过追踪该区间前后两个极值前缀的位置证明；短到不足两个 0 的情况已由第 3 步排除。这里依赖 $`n\ge8`$，长度 6 不满足该构造条件。

## 小规模例外

$`n=4,6`$ 时，代码直接对原排列做 BFS，顶点是排列，边是所有偶长区间的真实 `FakeSort`。最多只有 $`6!=720`$ 个状态，记录前驱还原最短构造，无需手工枚举特殊判定。

这一部分真的操作排列，包含值的相对大小，不只看二值模式。

## 正确性与操作预算

小规模 BFS 穷尽所有可达排列，判定与还原均正确。大规模算法先用二值结构固定最前两个 0 或最后两个 1，再在剩余不平衡区间上排序，最终模式为排序模式。局部模拟前已进行全局类内排序，模拟与真实操作一致；最后全局操作把值排好。

最多调用三个长区间 `Sort`，每次至多 $`2\lceil\log_2 n\rceil`$ 次操作，短区间修复至多 2 次，再加最终全局排序。$`n\le10^5`$ 时这个保守预算不超过 $`6\cdot17+3=105\lt 114`$。部分区间本身已排序时不会输出多余操作。

时间 $`O(n\log n)`$，空间 $`O(n)`$；小规模 BFS 只有常数大小状态空间。构造输出必须用 checker 重放验证，不能直接对比样例给出的某一组操作。

## 可迁移总结

困难排序操作可以先按值域阈值二值化，分析它如何移动分类位置；为确定模拟规则，允许用一次规范化操作整理类内次序。构造往往需要“让进度指标倍增”的不平衡子区间，操作上限必须把辅助规范化也算进去。本题细节密集，适合长期补题；当前最优先的提升目标仍是 D、B、J、I。
