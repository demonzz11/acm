# I · Round screws

[题单与难度](../README.md) · [C++17 参考代码](../std/I.cpp) · 官方题面 PDF 第 13 页

## 题意与约束

数组的价值是

```math
V(a)=a_1+a_n+\sum_{i=1}^{n-1}(a_i\oplus a_{i+1}).
```

每花 $`C`$ 可以把一个位置改成任意非负整数，最小化最终价值加修改代价。$`n\le10^5`$，$`a_i\lt 2^{18}`$，$`C\lt 2^{19}`$；总 $`n\le2\cdot10^5`$。

## 切入点：只记没改的位置

在两端加入固定虚拟值 $`a_0=a_{n+1}=0`$，原价值就是所有相邻异或之和。

异或满足数值三角不等式

```math
x\oplus z\le(x\oplus y)+(y\oplus z),
```

逐位看，一位若首尾不同，中间路径至少产生一次该位的变化；若相同，右侧该位的贡献非负。因此保留位置 $`j\lt i`$ 之间的修改位置，可以全部填成 $`a_j`$，把这段最小异或贡献降到 $`a_j\oplus a_i`$。

这说明应枚举保留点，而不是枚举每个被改位置填什么数。若填充值恰好等于某个原值，多算一次修改也没有关系：最优枚举可以把该位置额外保留，从而消除多算代价。

## DP

令 $`f_i`$ 为最后保留到位置 $`i`$ 的最小代价，$`f_0=0`$。转移为

```math
f_i=\min_{0\le j<i}\{f_j+(a_j\oplus a_i)+(i-j-1)C\}.
```

虚拟末点也按此式转移，$`f_{n+1}`$ 就是答案。定义

```math
g_j=f_j-(j+1)C,
```

则查询只需最小化 $`g_j+(a_j\oplus a_i)`$，再加 $`iC`$。

## 高低 9 位拆分

把值写成 $`a=512h+\ell`$，高低部分各有 512 种值。维护

```math
B[h][x]=\min_{j:\operatorname{high}(a_j)=h}\{g_j+(\operatorname{low}(a_j)\oplus x)\}.
```

插入一个保留点时，枚举全部 512 个低位查询值，更新它所在的行。查询 $`a_i=512h_i+\ell_i`$ 时，枚举 512 个高位：

```math
f_i=iC+\min_h\{B[h][\ell_i]+512(h\oplus h_i)\}.
```

低位和高位之间没有进位，式子精确成立。必须先查询再插入，防止当前点作为自己的前驱。虚拟起点插入的值是 0，$`g_0=-C`$。

## 正确性与复杂度

任意修改方案的保留点序列都对应 DP 路径，异或三角不等式给出 DP 不大于该方案；反过来，按前驱值填充每个间隙就能实现 DP 的每条边，因此最优值相等。高低位数据结构逐项精确表示原转移。

时间 $`O(n\sqrt{2^{18}})=O(512n)`$，空间 $`O(2^{18}+n)`$。DP 和负偏移都用 `long long`，不能用无符号数保存 $`g_j`$。

## 可迁移总结

序列修改题先尝试把连续修改段压成保留端点之间的一条边；再从 $`O(n^2)`$ 转移里抽取 $`i,j`$ 各自的项和真正的交叉项。交叉项是小值域异或时，高低位拆分很有用。练习方向：按保留点建 DP、值域分块、异或距离最小值。不要把本题 DP 的减法偏移当成线性基问题，两者解决的目标不同。
