## 如何复现

```bash
python verify.py
python verify.py --exhaustive
python verify.py --exhaustive --stress
```

固定随机种子为 2908。`--exhaustive` 扩大 C、H、L、M 的枚举范围；`--stress` 增加最大规模检查；`--only FGHJ` 可选择小规模验证题目，但所有代码仍统一编译，压力检查仍覆盖脚本定义的完整压力集合。编译文件和可执行程序放在系统临时目录。

## 验证的边界

- 小规模暴力、枚举和压力运行不能替代正确性证明，也不能证明任意平台均在时限内。
- F 的最大规模采用大量重复线段，侧重 I/O、排序和边界；独立随机几何检查见上表。
- E 的链用来检查差异位置增量更新，相同串用来检查计数与输入规模；两者不覆盖所有树形。
- K 官方题面与题解的时限描述不同，以当前提交站为准；实现采用官方 $`O(\log^3 n)`$ 方法，本地压力结果仅供参考。
- L、M 的最大规模只检查执行完成，独立答案核对集中在可暴力规模。
- 没有向 QOJ 发送提交，也没有为此创建账号或改动用户凭据。
