## 题意与范围

有 $`n`$ 种物品，每种数量无限，第 $`i`$ 种重量为 $`w_i`$。判断能否选出**恰好 $`n`$ 件**物品，使总重量恰好为 $`m`$。

$`T\le10^4`$、$`1\le n\le10^5`$、$`0\le w_i\le n`$、$`0\le m\le n^2`$，每个测试文件的 $`\sum n\le10^5`$。时间限制 8 秒，内存限制 1024 MiB。

官方样例：

```text
输入
4
5 25
0 0 0 0 5
5 11
4 4 4 5 5
5 0
1 2 3 4 5
5 25
0 1 2 3 4

输出
Yes
No
No
No
```

## 移动平均重量，使目标变小

重复出现的重量只需要记录是否存在。令

```math
B=\left\lfloor\frac mn\right\rfloor,\qquad r=m-nB,
```

并将每个重量改成 $`a_i=w_i-B`$。选出的件数仍为 $`n`$，因此原问题等价于选出 $`n`$ 个移位后的重量，使总和为 $`r`$。此时

```math
-B\le a_i\le n-B,\qquad 0\le r\lt n.
```

定义允许负指数的生成函数

```math
f(x)=\sum_{w\text{ 存在}}x^{w-B}.
```

目标是判断 $`[x^r]f(x)^n`$ 是否为正。直接保存全部次数仍可能需要 $`O(n^2)`$ 空间，关键是每次乘法只保留指数区间 $`[-n,n]`$。

## 为什么可以截断到 $`[-n,n]`$

先证明一个排列性质：若某个长度为 $`n`$ 的移位重量多重集合总和为 $`r\in[0,n)`$，则能将这些重量排列为 $`a_1,\ldots,a_n`$，使每个前缀和都落在 $`[0,n]`$。

设当前前缀和为 $`S\in[0,n]`$，剩余重量多重集合为 $`R`$。按以下规则选择下一项：

- 当 $`S=B`$ 时，任选一个重量。因为重量属于 $`[-B,n-B]`$，新前缀和属于 $`[0,n]`$。
- 当 $`S\lt B`$ 时，若还有正重量，选择一个正重量。新前缀和至少为 $`0`$、至多为 $`B-1+(n-B)\lt n`$。若没有正重量，则剩余项均非正，任意顺序的前缀和从 $`S`$ 单调下降至最终的 $`r\ge0`$。
- 当 $`S\gt B`$ 时，若还有负重量，选择一个负重量。新前缀和至少为 $`B+1-B\gt 0`$、至多为 $`n`$。若没有负重量，则剩余项均非负，任意顺序的前缀和从 $`S`$ 单调上升至最终的 $`r\lt n`$。

因此可以一直完成排列。注意规则的比较阈值是移位量 $`B`$。

任意连续区间的和等于两个前缀和之差，所以该排列中每个连续区间的和都属于 $`[-n,n]`$。

考虑快速幂对应的二叉乘法树：每个叶子代表一件物品，每个内部节点代表左右两个连续块的合并。将上述排列依次放到叶子上，每个内部节点的指数都是某个连续区间的和，都在 $`[-n,n]`$ 中。因此这个有效方案的所有中间项都会被保留。

反过来，截断后的每个非零项仍由真实的左右子方案相加产生，所以不会制造不存在的方案。由此可知，对快速幂的**每次乘法和平方**截断到 $`[-n,n]`$，最终目标 $`r`$ 的存在性保持不变。

不能只根据“最终目标很小”截断中间状态到 $`[0,n]`$：内部连续块可能有负和。需要保留对称区间 $`[-n,n]`$。

## 布尔卷积与 NTT

我们只关心一个指数是否可达，因此每次卷积后都将系数二值化：非零变成 $`1`$，零仍为 $`0`$。再截断到 $`[-n,n]`$，去掉两端零系数，继续进行二进制快速幂。

初始多项式的系数也是 $`0/1`$，重复重量不增加系数；快速幂的累乘结果从常数多项式 $`1`$ 开始。负指数用“数组第 $`0`$ 项的实际指数 `low`”表示。两个数组卷积后的起始指数是两个 `low` 之和，据此保留对应 $`[-n,n]`$ 的数组位置。

这里可以确定地使用模数 $`998244353`$ 的 NTT。任意一次卷积前，两侧系数均为 $`0/1`$，每侧至多有 $`2n+1`$ 项。所以任意一个**单轮整数卷积系数**至多为

```math
2n+1\le200001\lt 998244353.
```

因此一个正系数取模后不会变成 $`0`$，NTT 后判断非零等价于整数上的布尔卷积。每轮二值化使这个论证持续成立，不需要依靠随机性或多个模数。

线性卷积长度至多为 $`4n+1`$，补齐后的 NTT 长度至多为 $`2^{19}=524288`$，在该模数支持的 $`2^{23}`$ 范围内。平方时只需一次正变换；小数组乘法直接使用朴素卷积。

## 正确性证明

**移位等价性：** 每个选中重量减去 $`B`$，恰好选 $`n`$ 件便使总和减去 $`nB`$，所以原目标 $`m`$ 与新目标 $`r`$ 等价。

**截断完整性：** 任意有效选取都能按前述规则重排，使所有连续块的和落在 $`[-n,n]`$。快速幂乘法树的每个节点都可对应这样的连续块，所以其整条见证路径不会被截断，最终必然保留目标项。

**卷积可靠性：** 每个保留的非零项来自合法物品块的合并；二值化保留存在性，且单轮卷积系数严格小于模数，因此 NTT 不会把存在的方案误判为不存在，也不会制造假方案。

结合三点，快速幂最终目标 $`r`$ 的可达性与原问题一致，其目标项非零当且仅当题目有解。

## 复杂度与边界

每个多项式长度为 $`O(n)`$，一次卷积耗时 $`O(n\log n)`$；快速幂有 $`O(\log n)`$ 次卷积，总时间为 $`O(n\log^2 n)`$，空间为 $`O(n)`$。多组输入的时间为 $`O(\sum n\log^2 n)`$。

总重量 $`m`$ 和 $`n\min w_i,n\max w_i`$ 使用 64 位整数。若 $`m`$ 在这两个极值之外，直接回答 `No`；若等于任一极值，选择 $`n`$ 个该重量即可回答 `Yes`。这也覆盖 $`n=1`$、全部重量相同、全零重量及极端目标。初始 $`B\in[0,n]`$，所以所有叶子指数都处于截断区间内。

独立验证使用每层恰好多选一件物品的重量 DP，覆盖 $`n\le6`$ 的所有重量多重集合和所有目标，以及触发 NTT 的较大随机、稀疏重量小例，共 45,268 组；另验证两个 $`n=100000`$ 的完整卷积测试。未声称已在 QOJ 在线提交。
