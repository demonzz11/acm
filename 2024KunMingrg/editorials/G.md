## 题意

给定两个正整数 $`a,b`$。每轮选择一个仍为正数的数，将它减去当前的 $`\gcd(a,b)`$。求让两个数都变成 $`0`$ 的最少轮数。

数据范围为 $`1\le a\le b`$、$`a\le 5000`$、$`b\le 10^{18}`$；$`T\le 1000`$，每个测试文件满足 $`\sum a\le 10^4`$。时间限制 3 秒，内存限制 1024 MiB。

样例：

```text
输入
3
3 4
12 20
114 514

输出
3
4
6
```

## 一、除掉公因子不会改变答案

设 $`g=\gcd(a,b)`$，将状态改写为 $`(a/g,b/g)`$。之后每一步的最大公因数和被减去的数都会同比例缩小，因此操作序列可以在两个状态之间一一对应。

所以，可以在每次搜索时先除掉最大公因数，再交换两个数，使较小的数放在前面。此时两个数互质，每个操作都等价于将其中一个数减去 $`1`$；下一层再重新归一化。

如果归一化后的较小数为 $`1`$，答案恰好是 $`2`$：先将这个 $`1`$ 减到 $`0`$，再将另一个数减到 $`0`$。

## 二、为什么最多只需要 26 步

虽然 $`b`$ 可以达到 $`10^{18}`$，但我们只需要先把原来较小的数 $`a`$ 变成 $`0`$。此后，另一个数只需要一步即可归零。

观察两个数的奇偶性：

1. 如果两个数都是偶数，可以同时除以 $`2`$，答案不变。
2. 如果恰有一个奇数，最大公因数一定为奇数。操作这个奇数后，两个数都会成为偶数。
3. 如果两个数都是奇数，先操作 $`a`$，使它变成偶数；再操作另一个数，使它也变成偶数。若中途出现 $`0`$，则可以直接结束。

因此，每花费至多两次操作，就能把两个数同时除以 $`2`$。重复 12 轮后，$`a`$ 至多为

```math
\left\lfloor\frac{5000}{2^{12}}\right\rfloor=1.
```

至多再用一步将 $`a`$ 归零，最后用一步将 $`b`$ 归零，总共至多

```math
2\times 12+1+1=26
```

次操作。除以其他公因子只会进一步缩小状态，不影响这个上界。

## 三、迭代加深搜索

依次检查是否存在不超过 $`2,3,\ldots,26`$ 步的方案。第一次成功时的步数就是答案。

对于归一化后的互质状态 $`(a,b)`$，保留题目允许的两种选择：

```math
(a,b)\longrightarrow(a-1,b),\qquad
(a,b)\longrightarrow(a,b-1).
```

每个转移消耗一次操作，再对新状态除掉公因子。可以使用以下剪枝：

- 若一个数已经是 $`0`$，另一个数只需要一次操作。
- 若归一化后较小数为 $`1`$，还需要恰好两次操作。
- 否则两个数都大于 $`1`$ 且互质，第一步无法将任意一个数归零，因此至少还需要三步。
- 对每个归一化状态，记录已经搜索失败的最大剩余步数 $`k`$。以后如果剩余步数不超过 $`k`$，可以直接判定失败。这个缓存可在同一测试用例的多次迭代之间复用。

### 常数时间的最大公因数

设所有测试用例中较小数的最大值为 $`A`$，$`A\le5000`$。搜索中的较小数只会减小，利用

```math
\gcd(a,b)=\gcd(a,b\bmod a)
```

即可只查询 $`0\le r\lt a\le A`$ 的小数最大公因数。

按 $`a`$ 从小到大预处理：

```math
G[a][0]=a,\qquad
G[a][r]=G[r][a\bmod r]\quad(1\le r<a).
```

右侧所在的行已经计算完毕。实现用一维数组保存三角表，并用 `uint16_t` 存储结果；当 $`A=5000`$ 时，该表约占 25 MB。之后每次最大公因数查询只需要一次取模和一次数组访问。

## 正确性证明

**引理 1：** 同时除以最大公因数、交换两个数，都不改变最少操作次数。

除以最大公因数时，任意后续操作及其最大公因数都会按同一比例缩小，因此合法操作序列之间存在保留长度的双射；交换两个数则仅交换两个操作的名字。

**引理 2：** 对于剩余步数为 $`k`$ 的状态，搜索成功当且仅当存在不超过 $`k`$ 次操作的方案。

终止状态及较小数为 $`1`$ 的状态按所需的精确步数处理。其他状态先通过引理 1 归一化，此时最大公因数为 $`1`$；搜索完整枚举两种合法的第一步，随后递归检查剩下的 $`k-1`$ 步。失败缓存仅复用“更多或相同步数也无法完成”的结论，不会排除合法方案。因此结论成立。

**引理 3：** 任意满足题目范围的状态都存在不超过 26 步的方案。

前述奇偶构造最多用 24 步，将初始的 $`a\le5000`$ 缩小至 $`1`$，再用至多两步使两数归零。

**结论：** 迭代加深会由引理 3 在 26 步以内结束；由引理 2，第一次搜索成功的步数恰好为最少操作次数。

## 复杂度

预处理需要 $`O(A^2)`$ 时间和空间。设第 $`i`$ 个用例答案为 $`D_i\le26`$，二叉搜索树和迭代加深的节点总数为 $`O(2^{D_i})`$。最大公因数查询为 $`O(1)`$，哈希表查询期望为 $`O(1)`$。

本实现的失败状态记忆化还可以给出更紧的界。固定一个初始状态 $`(a_0,b_0)`$，设搜索到某个正数状态时，历次归一化除掉的公因数乘积为 $`q`$。暂时保留两个数的原始身份，以免交换顺序干扰记号。每次实际操作在原坐标中减掉的量，是当时的缩放系数，至多为最终的 $`q`$。搜索深度至多为 $`D`$，因此当前归一化坐标 $`(u,v)`$ 满足

```math
u=\frac{a_0-X}{q},\quad v=\frac{b_0-Y}{q},\qquad
0\le X,Y\le Dq.
```

因为 $`u`$ 是正整数，所以 $`q\le a_0`$。对于每个固定的 $`q`$，两个坐标分别落在至多 $`D+1`$ 个整数中：

```math
u=\left\lfloor\frac{a_0}{q}\right\rfloor-k,\quad
v=\left\lfloor\frac{b_0}{q}\right\rfloor-l,\qquad 0\le k,l\le D.
```

交换两个数只将候选状态映射为统一的排序形式，不增加状态数。因此缓存状态总数至多为 $`a_0(D+1)^2`$。同一个失败状态只有在严格增大的剩余步数下才会再次展开，所以最多展开 $`D`$ 次；最终成功而未写入失败缓存的节点只位于返回成功的那条路径上，至多有 $`D`$ 个。

结合二叉树上界，总期望时间可以写成

```math
O\!\left(A^2+\sum_i\min\{2^{D_i},\ a_i(D_i+1)^3\}\right),
```

或使用较宽松的 $`O(A^2+\sum_i a_iD_i^3)`$。空间为

```math
O\!\left(A^2+\max_i a_i(D_i+1)^2\right),
```

因为每个用例开始前都会清空失败缓存。递归栈深度不超过 26。

## 原代码容易漏掉的路径

归档快照 [original/G.cpp](../original/G.cpp) 中的质因子跳转版本，只保留了“连续减小 $`b`$，直到遇到某个质因子”的转移，这会漏掉提前切换操作对象的最优方案。下面的结论针对这份保存的快照；用户目录中的实时源文件可能已经继续修改。

例如 $`(a,b)=(11,86)`$ 的正确答案为 $`5`$：

```text
(11,86) -> (11,85) -> (10,85) -> (5,85) -> (0,85) -> (0,0)
```

第一步只减小 $`b`$ 一次，此时还没有让 $`\gcd(11,b)`$ 变大，就立即改为操作 $`a`$。原压缩搜索实测输出 $`6`$。因此参考代码保留每一步的两个完整分支。
