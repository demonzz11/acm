# D. Dolls / 套娃

- 题面：[QOJ 比赛](https://qoj.ac/contest/1871?v=1)、[官方题面第 9–10 页](https://ucup.ac/statements/statements-3-20.pdf)
- 参考：[官方中文题解第 35–39 页](https://ucup.ac/tutorials/tutorials-3-20-zh.pdf)
- 代码：[C++17 标准解](../solutions/D.cpp)
- 限制：1 秒、1024 MB；$`T\le10^4`$，$`n\le10^5`$，$`\sum n\le10^5`$。

## 题意

给定 $`1\ldots n`$ 的排列，最初每个位置放一个对应大小的套娃。一个已经合并的套娃集合用其中最小值 $`l`$ 和最大值 $`r`$ 表示。两个相邻集合允许合并，当且仅当

```math
r_1<l_2\quad\text{或}\quad r_2<l_1.
```

合并后取二者最小值和最大值，并保持位置相邻关系。求最多能执行多少次合并。

## 1. 转成最少区间划分

每次合并都只涉及相邻集合，所以最终每个集合对应原排列中的一个连续区间。若最后剩 $`p`$ 个区间，恰好执行了 $`n-p`$ 次合并。

问题变为：将排列划分成尽可能少的连续区间，使每个区间都能够合并成一个集合。

## 2. 判定一个区间能否全部合并

先将待判定区间的值按大小离散化为 $`0\ldots L-1`$。只需相对大小，原数值之间的空隙不影响可合并条件。

称两个集合的值域**紧密相邻**，如果它们对应的排名区间满足

```math
r_1+1=l_2\quad\text{或}\quad r_2+1=l_1.
```

从左到右用栈维护集合，先压入当前单点，然后只要栈顶两段紧密相邻，就立即合并，并继续尝试新栈顶。最后栈中只有一段，则判定成功。

这里每个栈段都恰好覆盖某个连续排名区间。紧密合并不会在排名范围中留下缺口。

为什么只需要紧密合并？假设整个区间确实能够合成一个。在完整合并方案的最后一次操作中，两个子集合的值域不交，而且并集覆盖所有排名 $`0\ldots L-1`$，因此它们必然是两个紧密相邻的连续排名区间。递归观察两侧子方案，同样得到每次合并都可以是紧密合并。

紧密合并的顺序不影响最终是否只剩一段。考虑同一状态中两种可选的紧密合并：

- 涉及四个不同集合时，两次合并互不影响，交换执行顺序得到同一状态。
- 共用中间集合时，涉及连续三段 $`A,B,C`$。它们的排名区间两两不交；若 $`A,B`$ 紧密相邻且 $`B,C`$ 紧密相邻，则 $`A,C`$ 必须分别位于 $`B`$ 的两侧，三段的排名范围整体升序或整体降序。无论先合并哪一对，随后都能把三段合为同一个排名区间。

每次合并都使段数减少，因此不存在无限过程。上述“两个选择总能再走到同一状态”的性质，按剩余可操作次数归纳，保证任意合并顺序的最终不可合并状态都相同。于是只要存在完全紧密合并方案，栈选择的合并顺序也一定会得到一段。

因此，能完全合并的区间最终会被栈压缩成一段；栈压缩成一段也直接给出合法方案，判定充要。

一次判定排序离散化需 $`O(L\log L)`$，栈部分每个元素至多压入、合并各一次，为 $`O(L)`$。

## 3. 取最长可合并前缀

有一个关键的遗传性质：一个可完全合并的区间，其任意连续子区间也可完全合并。

证明可以限制原合并二叉树：删除子区间外的叶子；一侧被全部删除的合并节点直接收缩；两侧都保留时，它们的最大最小范围只会缩小，原来不交的关系仍然成立，所以限制后的合并过程依然合法。

现在从左向右处理。在当前左端点 $`l`$，选择最长的可合并前缀 $`[l,r]`$，将其作为一段，然后处理剩余后缀。

这个贪心不会增加段数。考虑某个最优划分，最长可合并前缀一定至少覆盖它的第一段。将前面被覆盖的段全部替换为 $`[l,r]`$；如果 $`r`$ 切在某个段中间，保留该段在 $`r`$ 之后的后缀，这个后缀由遗传性质仍可完全合并。替换后段数不增。因此存在以贪心第一段开头的最优划分，对剩余后缀归纳即可。

遗传性质还说明：固定左端点时，区间是否可完全合并，随长度从真变为假，适合二分寻找最大长度。

## 4. 倍增，再二分

不能对每一段直接在整个剩余后缀上二分。若最优段都很短，这样会多次检查巨大的区间。

从长度 $`1`$ 开始，尝试 $`2,4,8,\ldots`$，直到首次失败或覆盖整个剩余后缀，再在最后成功长度与失败长度之间二分。

设当前最长可合并长度为 $`L`$。所有倍增判定的长度呈几何级数，总长度为 $`O(L)`$；二分有 $`O(\log L)`$ 次，每次检查长度为 $`O(L)`$。故寻找这一段耗时

```math
O(L\log^2(L+1)).
```

所有贪心段的长度之和为 $`n`$，得到总体 $`O(n\log^2 n)`$。

## 正确性证明

**引理 1：** 栈判定成功，当且仅当被检查区间能够完全合并。

栈进行的每次紧密合并都满足题目条件，所以成功时直接构成合法方案。若存在完整方案，离散化后其合并树的每个节点都覆盖连续排名区间，所以只涉及紧密合并。紧密合并的两个不同选择要么可以交换，要么能继续合并同一个三段区间，因此最终不可合并状态与选择顺序无关。栈在每次加入单点后穷尽栈顶合并；此前的相邻段已经不可合并，新产生的机会只能包含新栈顶，所以最终得到完整不可合并状态。该状态必须为一段。

**引理 2：** 可完全合并区间的任意连续子区间也可完全合并。

将完整合并二叉树限制到该子区间；在所有仍有两侧的合并中，两侧值域只会缩小，不交关系保持成立。

**引理 3：** 最长可合并前缀贪心产生最少段数。

用贪心前缀替换最优划分中被它覆盖的前几段。若有最后一段被部分覆盖，则保留其后缀，由引理 2 仍然合法，段数不增。于是存在第一段与贪心相同的最优解；对后缀归纳。

由引理 1，倍增和二分找到的前缀确实是最长合法前缀。由引理 3，代码求得最少最终段数 $`p`$，所以输出 $`n-p`$ 正是最多合并次数。

## 复杂度与实现边界

时间为 $`O(n\log^2 n)`$，额外空间为 $`O(n)`$。多组数据按各自长度累计。

- 离散化必须针对当前检查区间，不能要求原数值恰好相差 $`1`$。
- 两个相邻集合的排名区间可以升序或降序，两个方向都需要检查。
- 二分右端点先通过倍增找到，避免短区间重复检查整个长后缀。
- $`n=1`$ 时不需要合并，输出 $`0`$。
- 已有最长成功区间覆盖整个后缀时，直接结束该段，不制造不存在的失败端点。
