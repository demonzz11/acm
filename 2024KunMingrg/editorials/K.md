# K. Key Recovery / 密钥恢复

- 题面：[QOJ 比赛](https://qoj.ac/contest/1871?v=1)、[官方题面第 20–22 页](https://ucup.ac/statements/statements-3-20.pdf)
- 参考：[官方中文题解第 64–70 页](https://ucup.ac/tutorials/tutorials-3-20-zh.pdf)
- 代码：[C++17 交互参考解](../solutions/K.cpp)
- 限制：1 秒、1024 MB，最多 4096 次询问。本题采用官方积分攻击；**候选筛选恒正确，候选能否在询问限额内唯一化使用概率分析，并非已证明的无条件恢复保证。**

## 题意与交互协议

一个固定的未知 32 位密钥 $`k`$ 用来加密 8 个 4 位数，记密钥的 8 个半字节为 $`k_0,\ldots,k_7`$。加密流程是连续六轮 `xor, perm, mix`，最后再做一次 `xor`；所有轮次使用同一个密钥。

三个操作为：

```math
X_k(x)_i=x_i\oplus k_i,
\qquad P(x)_i=p_{x_i},
```

其中题目固定置换

```text
p = [7,0,5,6,b,f,4,3,1,d,c,e,8,9,a,2]
```

令 $`\tau(x)`$ 为有限域 $`\mathrm{GF}(16)`$ 中乘以 $`2`$：

```math
\tau(x)=
\begin{cases}2x,&x\lt8,\\ 2(x\oplus8)\oplus3,&x\ge8.\end{cases}
```

令 $`\rho(i)`$ 表示索引 $`i`$ 的**三位循环右移一位**，则

```math
M(x)_i=x_{\rho(i)}\oplus\tau(x_{\rho(i)\oplus1}).
```

例如 $`\rho(1)=4`$，不能将其写成普通整数右移得到 $`0`$。$`\tau`$ 的左移需要丢弃超过四位的部分。

程序输出 `? in7in6in5in4in3in2in1in0`，8 位小写十六进制必须保留前导零，随后刷新缓冲。交互器返回对应的 8 位输出。最多询问 4096 次。最后输出 `! k`，其中 $`k`$ 使用非负十进制、范围 $`[0,2^{32}-1]`$，然后立即退出。

如果收到 `-1` 或输入流关闭，应立即退出。没有普通题目的 $`T`$ 或初始输入。

## 1. 混合操作是可逆线性变换

在不考虑最后的索引置换时，一对相邻输入 $`(a,b)`$ 变为

```math
(a\oplus\tau(b),\ b\oplus\tau(a)).
```

$`\tau`$ 对异或线性，故 $`M`$ 也是线性变换。代码枚举 $`16^2=256`$ 个输入对，建立输出对到输入对的逆表，并检查没有重复输出；因此可以直接求 $`M^{-1}`$。这里反向索引使用三位循环左移。

## 2. 256 个明文具有第五轮积分性质

一次选择明文中其余六个半字节为常量，让 $`x_0,x_1`$ 独立取遍 $`0\ldots15`$，询问全部 256 个输入。

记 16 个输入构成的小组中，一个位置具有如下性质：

- $`A`$：16 个值恰好是 $`0\ldots15`$ 的一个排列；
- $`C`$：16 个值全部相同；
- $`B`$：16 个值的异或和为 $`0`$。

异或常量保持 $`A,C,B`$；固定置换保持 $`A,C`$。混合时，$`A`$ 与 $`C`$ 得到两个 $`A`$，两个 $`A`$ 得到两个 $`B`$：后者来自线性关系和 $`0\oplus1\oplus\cdots\oplus15=0`$，不要求两个排列相互独立。

首轮混合时，前两个半字节的 256 种组合经过可逆的二元映射，仍取遍所有组合。按混合后对应的一侧半字节分成 16 组，每组另一侧遍历全部 16 种值。所以每组具有“一个 $`A`$、其余为 $`C`$”的状态；这种分组只用于证明，程序不需要知道组别。

接下来的混合逐轮使活动位置数量变为 $`2,4,8`$。在第五轮混合后，每组的全部位置具有性质 $`B`$。16 组异或零仍是零，得到可直接观察的整体性质：

```math
\bigoplus_{x_0=0}^{15}\ \bigoplus_{x_1=0}^{15}
Z_i(x_0,x_1)=0,\qquad 0\le i<8,
```

其中 $`Z`$ 表示第五轮混合后的状态。

## 3. 将最后的密钥移到混合之前

最后一轮为

```math
C=M(P(Z\oplus k))\oplus k.
```

利用 $`M^{-1}`$ 的线性性，令等价密钥 $`e=M^{-1}(k)`$，则

```math
W=M^{-1}(C)=P(Z\oplus k)\oplus e.
```

枚举一个半字节 $`e_i\in[0,15]`$，反向计算

```math
P^{-1}(W_i\oplus e_i)=Z_i\oplus k_i.
```

256 个值异或时，常量 $`k_i`$ 出现偶数次，抵消。于是每个正确候选必然满足

```math
\bigoplus_{256\text{ 个密文}}
P^{-1}(W_i\oplus e_i)=0.
```

每个位置只需要枚举 16 种值，不必直接枚举完整 32 位密钥。将多批明文的筛选结果求交，保留所有仍可能正确的等价密钥半字节。

## 4. 完整加密验证候选

筛选条件是必要条件，不能因为某个候选通过积分筛选就认定它正确。

当八个半字节的候选数量乘积不超过 65536 时，代码枚举全部组合，令 $`k=M(e)`$，然后用完整六轮加密计算每个已询问明文，逐个比较真实密文。不符的候选立即淘汰。

如果只剩一个完整密钥，则可以确定它就是正确密钥：真实密钥从未被积分筛选删除，必然位于所枚举的全部候选组合中，而且能通过所有完整加密验证。

如果剩余多个密钥，继续选择其余六个半字节的新随机常量，发起下一批 256 次询问。已验证候选的半字节投影也用于缩小下一批搜索范围。最多进行 16 批，即 4096 次询问。

## 概率依据与限制

官方题解将一个错误半字节候选在一批中仍通过异或检验的概率近似为 $`1/16`$。若将不同随机常量产生的检验近似视作独立，16 批后一个错误候选存活的概率约为

```math
(1/16)^{16}=2^{-64}.
```

这属于对密码结构混合效果的启发式估计。它不是针对该固定置换、所有密钥和所有批次相关性的严格概率上界，不能写成无条件正确性证明。

这份实现通过完整加密复核显著降低错误作答风险；在完整枚举后只剩一个候选的情况下，答案具有确定性保证。仍有两种没有无条件排除的恢复失败情形：

1. 4096 次后依然有多个密钥与所有已观察明密文一致，代码只能从这些已验证候选中选择第一个，可能不是交互器密钥。
2. 4096 次后候选组合数始终超过 65536，代码不进行无法控制规模的完整枚举，并以未恢复成功结束。

本地随机、边界密钥测试没有观察到上述情形。不能据此证明它们永远不会发生。本题交互器非自适应，密钥在交互开始前固定，随机明文常量符合官方分析所使用的条件。

## 正确性说明

**真密钥不会被过滤。** 第五轮积分性质成立；移至混合前的等价钥满足所有单半字节异或检验，因此对应候选始终保留。

**唯一完整候选正确。** 全部半字节组合中包含真等价钥。完整加密验证不会删除真钥，且准确拒绝任何与已观察输出不一致的密钥。如果剩一个，它必然是真钥。

**查询数量合法。** 每批固定 256 次，最多 16 批，总数不超过 4096。每次询问输出后立刻刷新，最终回答使用 `uint32_t` 输出完整非负十进制值。

此处不声称“4096 次一定唯一化”，其限制已在上文明确说明。

## 复杂度

设批次数为 $`R\le16`$，每批 $`256`$ 次询问。积分筛选的计算量为 $`O(R\cdot256\cdot8\cdot16)`$，逆混合为每个密文常数次表查询。保存全部观察的空间为 $`O(256R)`$。

设某次完整验证涉及 $`C\le65536`$ 个候选、已有 $`Q\le4096`$ 个明密文，完整验证的保守最坏计算量为 $`O(CQ\cdot6\cdot8)`$。错误候选通常在第一个明密文就被拒绝；真候选比较全部观察。官方概率模型下，候选空间很快变小。不能把这种实际速度当成所有随机路径上的最坏时限证明。

## 交互样例与验证

题面的示例密钥为十进制 `998244353`，对应：

```text
程序输出：? 04f37255
交互返回：acf7e10b
程序输出：? 9090cfca
交互返回：105092e0
程序输出：! 998244353
```

它只用于演示协议，本程序会采用自己的积分批次查询。

[独立 Python 交互器](../tests/check_K.py) 使用官方固定置换与独立方向实现的混合算法，先核对以上两个明密文，再驱动标准解的真实标准输入输出。它检查前导零、小写字符、最多 4096 次询问、最终无符号密钥、回答后退出，以及收到 `-1` 后退出。

压力模式测试 64 个边界与随机密钥，并直接检查随机密钥下第五轮积分异或性质。一次本地压力运行中，64 个密钥全部在首批 256 次询问后通过完整验证并唯一恢复。此记录是实测证据，不是概率保证。完整源码见 [solutions/K.cpp](../solutions/K.cpp)。
