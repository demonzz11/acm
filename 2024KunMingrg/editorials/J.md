# J. Just another Sorting Problem（又一个排序问题）

- 比赛：[2024 ICPC 昆明区域赛 / QOJ 1871](https://qoj.ac/contest/1871?v=1)
- 题面：[官方英文题面，第 19 页](https://ucup.ac/statements/statements-3-20.pdf)
- 参考：[官方中文题解，第 8–11 页](https://ucup.ac/tutorials/tutorials-3-20-zh.pdf)
- 标准解：[C++17 源码](../solutions/J.cpp)
- 标签：博弈、排列、不变量

## 题意

给定长度为 $`n`$ 的排列 $`p`$，以及先操作的人 `Alice` 或 `Bob`。两人轮流操作，均不能跳过回合：

- Alice 可以交换任意两个不同位置的数字。
- Bob 只能交换两个相邻位置的数字。

**任何一人操作后**，如果排列变为升序，Alice 立即获胜。若 Bob 能使排列永远无法变为升序，则 Bob 获胜。求双方采用最优策略时的赢家。

数据范围：$`1\le T\le 10^4`$，$`2\le n\le 10^5`$，所有测试的 $`n`$ 之和不超过 $`10^5`$。输入保证 $`p`$ 是排列，且初始排列不是升序。

## 结论

令 $`k`$ 为没有归位的位置数量，即

```math
k=\#\{i\mid p_i\ne i\}.
```

非升序排列的 $`k`$ 不可能等于 $`1`$。赢家为：

| 长度 | 先手 | Alice 获胜的条件 |
| :--- | :--- | :--- |
| $`n=2`$ | 任意 | 总是获胜 |
| $`n=3`$ | Alice | $`k=2`$ |
| $`n=3`$ | Bob | $`k=3`$ |
| $`n\ge4`$ | Alice | $`k=2`$ |
| $`n\ge4`$ | Bob | 从不获胜 |

因此，只需读入时统计 $`k`$。

## 推导与正确性证明

### 1. Alice 能否一步获胜？

交换仅影响两个位置，所以当 $`k\ge3`$ 时，Alice 不可能一步排好序。

当 $`k=2`$ 时，设没有归位的位置为 $`a,b`$。因为其余位置都已归位，且每个数字只出现一次，必有 $`p_a=b,p_b=a`$。Alice 交换这两个位置即可获胜。

故对于非升序排列，Alice 能一步获胜当且仅当 $`k=2`$。

### 2. 当 $`n\ge4`$ 时，Bob 能维持什么？

证明：**对任意非升序排列，Bob 总能通过一次相邻交换，使交换后至少有三个位置没有归位。**

分两种情况。

**存在已归位的位置。**

因为排列不是升序，也存在没有归位的位置。沿着位置顺序，必能找到一对相邻位置，其中恰有一个已经归位。交换这一对后：

- 原本已归位的位置收到其他数字，变为未归位。
- 原本未归位的位置收到邻居的下标，也不会归位。

因此 $`k`$ 增加 $`1`$，而原来的 $`k\ge2`$，所以新的 $`k\ge3`$。

**所有位置都没有归位。**

考虑相邻对 $`(1,2)`$ 与 $`(2,3)`$。它们不可能同时满足“两个数字恰好互换”：前者要求 $`p_2=1`$，后者要求 $`p_2=3`$。

因此至少有一对不是这样的二元环，Bob 选择交换它。只有交换的两个位置可能归位；如果它们同时归位，那么交换前就必须恰好互换，与选择条件矛盾。因此至多一个位置归位，交换后的未归位位置数至少为

```math
n-1\ge3.
```

上述两种情况证明了 Bob 的策略始终存在。

如果 Alice 没有在第一回合直接获胜，一旦轮到 Bob，他就能让下一次 Alice 回合开始时 $`k\ge3`$。Alice 这一回合无法获胜，操作后仍是非升序排列，Bob 可以再次采用相同策略。如此反复，Alice 永远无法获胜，故 Bob 获胜。

所以当 $`n\ge4`$ 时，只有 `Alice` 先手且 $`k=2`$ 才是 Alice 获胜。

### 3. 当 $`n=2`$ 时

初始排列只能是 $`[2,1]`$。不管谁先操作，唯一的交换都会排好序。题目规定即使是 Bob 排好序，也由 Alice 获胜，因此答案总是 `Alice`。

### 4. 当 $`n=3`$ 时

非升序排列只有两类：

- $`k=2`$：一个二元环，另外一个位置已经归位。
- $`k=3`$：一个三元环，即 $`[2,3,1]`$ 或 $`[3,1,2]`$。

对三元环交换任意两个位置，结果必是一个二元环，故 $`k`$ 从 $`3`$ 变为 $`2`$。对二元环，交换该环的两个位置会排好序；交换其他任意一对，则会得到三元环。

于是：

- **Alice 先手，$`k=2`$**：立即排好序，Alice 获胜。
- **Alice 先手，$`k=3`$**：无论如何交换，都会把 $`k=2`$ 的状态交给 Bob。Bob 有两种相邻交换可选，至多一种会排好序，选择另一种便会让 $`k=3`$。Alice 再次面对三元环，循环可以一直延续，Bob 获胜。
- **Bob 先手，$`k=2`$**：Bob 同样选择不会排好序的相邻交换，让 Alice 面对 $`k=3`$，进入上述循环，Bob 获胜。
- **Bob 先手，$`k=3`$**：Bob 无论交换哪一对相邻位置，都将得到 $`k=2`$。随后 Alice 一步排好序，Alice 获胜。

这与判定表完全一致，算法正确。

## 复杂度

每组测试时间复杂度为 $`O(n)`$，所有测试合计为 $`O(\sum n)`$；只统计未归位数量，无需保存排列，额外空间复杂度为 $`O(1)`$。

## 样例

输入：

```text
3
2 Alice
2 1
3 Bob
1 3 2
10 Bob
1 2 3 4 5 6 7 8 10 9
```

输出：

```text
Alice
Bob
Bob
```

第二组中，Bob 可以交换位置 $`1,2`$，得到 $`[3,1,2]`$，随后在二元环与三元环之间维持循环。第三组虽然 Bob 可以通过交换末尾两项直接让 Alice 获胜，但最优策略会避免这样做。

## C++17 标准解

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int n;
        string first;
        cin >> n >> first;

        int wrong = 0;
        for (int i = 1; i <= n; ++i) {
            int p;
            cin >> p;
            wrong += (p != i);
        }

        bool alice_wins;
        if (n == 2) {
            alice_wins = true;
        } else if (first == "Alice") {
            alice_wins = (wrong == 2);
        } else {
            alice_wins = (n == 3 && wrong == 3);
        }
        cout << (alice_wins ? "Alice" : "Bob") << '\n';
    }
    return 0;
}
```

## 实现与验证说明

- 要判断的是最终由谁获胜，不能按“谁执行了排序交换”判断。
- 初始排列保证不是升序，因此 $`k=0`$ 不会出现；也不会有 $`k=1`$。
- `Alice` 和 `Bob` 的大小写必须与题面一致。
- 原目录的 `J.cpp` 在合法输入上的判定与此标准解一致；其中 $`k=0`$ 的分支属于题目保证下不会触发的情况。
- 验证枚举了 $`2\le n\le8`$ 的全部排列及两种先手，排除初始升序排列后共 **92,450** 个状态。采用有限状态图上的逆向传播计算 Alice 的必胜吸引域：Alice 回合有一个后继必胜即可；Bob 回合须所有后继均使 Alice 必胜。未进入吸引域的状态允许 Bob 永远避开终点，因而该方法无需猜测最大回合数。全部结果与上述判定一致，原代码和标准解也都通过这些输入及官方样例。

证明只需要 Bob 令操作后 $`k\ge3`$，不需要声称他总能令 $`k`$ 恰好增加 $`1`$。例如 $`[2,3,4,1]`$ 的三种相邻交换都会把 $`k`$ 从 $`4`$ 减为 $`3`$，但依然足以阻止 Alice 下一步获胜。
