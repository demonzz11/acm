# 原始来源档案

阅读题目请从 [比赛题单与难度排行](../README.md) 进入 [整理后的中文题面](../statements/) 和 [中文题解](../solutions/)。这些正文已整理公式、样例代码块和链接。

本目录保存 QOJ 中英文抓取、比赛身份记录和官方 PDF 的原始提取文本，供核对来源。它们的 Markdown 排版不等同于原网页或 PDF：样例可能没有围栏，PDF 的上下标、矩阵、图形和表格可能被压平或丢失。

- [官方中文题解 PDF](https://ucup.ac/tutorials/tutorials-4-e1-zh.pdf)：公式、图和现场通过情况以 PDF 为准。
- [题解提取文本](editorial-proxy.md)：保留原始提取内容，不适合作为渲染后的题解阅读。
- [比赛身份](contest-index.md) 与 [题号索引](problem-index.md)：用于核对年份、场次及 QOJ 题号。
- `A-qoj.md` 至 `M-qoj.md` 为英文抓取，`A-qoj-zh.md` 至 `M-qoj-zh.md` 为中文抓取。
