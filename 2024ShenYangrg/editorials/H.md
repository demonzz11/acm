# H · Guide Map：导游地图

[返回题单](../README.md) · [C++17 实现](../solutions/H.cpp) · [官方题面，第 15 页](https://ucup.ac/statements/statements-3-19.pdf#page=15) · [官方题解，第 23–25 页](https://ucup.ac/tutorials/tutorials-3-19-zh.pdf#page=23)

## 题意与约束

$`n`$ 个点构成完全图，其中 $`n-2`$ 条风景边恰好构成两棵树。选择一些边作为地图，从点一开始，每次走向地图中编号最小的未访问邻点，无法前进则沿首次到达的边退回。要求经过全部风景边，且至多经过一条不同的非风景边。求合法地图数，对 $`998244353`$ 取模。$`2\le n\le2\cdot10^5`$。

“地图包含一条边”不等于“旅行经过这条边”：指向已访问点的边不会被走过。这正是需要计数的自由度。

## 固定 DFS 树时，哪些边可以任选

旅行就是邻接点按编号递增的 DFS。先固定一棵以一为根的 DFS 树。对于树边 $`u\to v`$，$`u`$ 可以额外连向 $`v`$ 子树中编号大于 $`v`$ 的任意点 $`w`$。这些边不会抢在 $`v`$ 之前被选中，等 $`v`$ 子树遍历完，它们指向的点都已访问。

其余额外边都不合法：不同子树之间的边会改变 DFS 树；连向子树内编号小于 $`v`$ 的点会抢先访问。于是固定 DFS 树对应 $`2^K`$ 张地图，其中：

```math
K=\sum_{u\to v}\left|\{w\in\mathrm{subtree}(v):w\gt v\}\right|.
```

## 枚举桥边并分离贡献

记含点一的风景树为 $`T_1`$，另一棵为 $`T_2`$。如果两棵树都被访问，DFS 树必须是风景边加上一条桥边 $`(p,q)`$，其中 $`p\in T_1,q\in T_2`$。不同桥边的 DFS 树不同，地图不会重复计数。

将 $`T_1`$ 固定以一为根，记其内部贡献为 $`K_1`$。令 $`C_2(x)`$ 为 $`T_2`$ 中编号大于 $`x`$ 的点数。将 $`T_2`$ 以 $`q`$ 为根时，其内部贡献记为 $`K_2(q)`$。

桥边贡献为 $`C_2(q)`$。对 $`T_1`$ 中从一到 $`p`$ 的路径，每条父子边 $`u\to v`$ 的子树额外包含整个 $`T_2`$，所以增加 $`C_2(v)`$。定义：

```math
P(p)=\sum_{v\in\mathrm{path}(1,p)\setminus\{1\}}C_2(v),
\qquad Q(q)=K_2(q)+C_2(q).
```

固定桥边的指数就是 $`K_1+P(p)+Q(q)`$。因此双重枚举化为乘法：

```math
\mathrm{ans}_{\mathrm{bridge}}
=2^{K_1}\left(\sum_{p\in T_1}2^{P(p)}\right)
\left(\sum_{q\in T_2}2^{Q(q)}\right).
```

这里不能漏掉 $`C_2(q)`$，它属于桥边本身，而不是 $`T_2`$ 的内部树边。

## 如何求所有根的内部贡献

先把 $`T_2`$ 任选一点为根。对于父子边 $`u\to v`$，令：

```math
A=\left|\{w\in\mathrm{subtree}(v):w\gt v\}\right|,
\qquad
B=\left|\{w\notin\mathrm{subtree}(v),\ w\in T_2:w\gt u\}\right|.
```

把根从 $`u`$ 换到 $`v`$ 时，仅这一条边反向，其他边方向不变，因此：

```math
K_2(v)=K_2(u)-A+B.
```

DFS 序将子树变为连续区间。按 DFS 序对点编号建立可持久化线段树，就能查询“某个区间内编号大于某值的点数”，用来计算 $`K_1`$、初始 $`K_2`$ 和所有换根转移。$`P`$ 则沿 $`T_1`$ 自顶向下累加。

## 孤立点特判

当 $`T_2`$ 只有一个点时，也可以完全不访问它。此时所有跨树边必须不出现，而 $`T_1`$ 的内部地图仍有 $`2^{K_1}`$ 种，需要额外加上这一项。

特别地 $`n=2`$ 时没有风景边，包含唯一道路和不包含道路都合法，答案为二。

## 正确性与复杂度

固定 DFS 树的额外边条件既必要又充分；桥边唯一确定两棵风景树连接后的 DFS 树。指数被准确拆成内部贡献、桥边贡献和祖先路径贡献，换根公式准确计算所有内部贡献，孤立点情形补齐未访问另一棵树的地图。因此结果恰好覆盖全部合法地图。

时间 $`O(n\log n)`$，空间 $`O(n\log n)`$。所有 DFS 使用显式栈，避免链形树递归溢出。自由边数量可达二次量级，指数和路径累计量使用 `long long`。

## 补题切入点

先完成“固定一棵 DFS 树，有多少原图”的子问题，再练换根与二维数点。不要直接枚举所有桥边，那会有二次复杂度。
