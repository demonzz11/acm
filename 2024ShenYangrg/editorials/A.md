# A · Safety First：安全第一

[返回题单](../README.md) · [C++17 实现](../solutions/A.cpp) · [官方题面，第 2–3 页](https://ucup.ac/statements/statements-3-19.pdf#page=2) · [官方题解，第 26–29 页](https://ucup.ac/tutorials/tutorials-3-19-zh.pdf#page=26)

## 题意与约束

有 $`n`$ 段长度为正整数、从左到右不增的梯子。第一段下端落地；后续每段的下端或上端与前一段上端锁定。问最终高度恰为 $`m`$ 的方案数，对 $`998244353`$ 取模。长度序列或锁定方式不同都算不同方案。

有 $`T\le 10^5`$ 次询问，$`1\le n,m\le2000`$。需要预处理整张答案表，再逐次回答。

## 从几何转成标记序列

第一段最长，必然贡献高度。此后，如果接下一段的下端，高度增加该段长度；如果接上端，高度不变。由于长度不增，后者不会使最低点低于地面，也不会产生额外的最高点。

因此给每段一个标记 $`e_i\in\{0,1\}`$，其中 $`e_1=1`$，答案就是满足下面条件的带标记序列数量：

```math
d_1\ge d_2\ge\cdots\ge d_n\ge1,
\qquad \sum_{i=1}^{n} e_i d_i=m.
```

标记为零的段也占用一个位置，不能删掉；相等长度的不同位置，其标记仍然可以不同。

## 用两种 DP 分开处理长段和短段

设本次询问的最大参数为 $`N,M`$，取阈值 $`B=\lfloor\sqrt M\rfloor+1`$。

先考虑所有长度至少为 $`B`$ 的段。定义 $`F_{i,j,h}`$ 为已经放入 $`i`$ 段，其中 $`j`$ 段贡献高度，当前高度为 $`h`$ 的方案数。构造非增序列有两个互斥的末步：

- 最短段恰为 $`B`$：删去最后一段。它可以不贡献高度，或贡献 $`B`$。
- 最短段大于 $`B`$：所有段长度同时减一，高度减少 $`j`$。

因此，除第一段不能不贡献高度外，有：

```math
F_{i,j,h}
= [i\gt1]F_{i-1,j,h}
+F_{i-1,j-1,h-B}
+F_{i,j,h-j}.
```

初值为 $`F_{0,0,0}=1`$，其余非法状态为零。因为 $`jB\le h\le M`$，只需保留 $`j\le\lfloor M/B\rfloor`$。按 $`i`$、$`j`$、$`h`$ 递增计算，$`i`$ 这一维可以滚动。

将每行累加到 $`A_{i,h}=\sum_j F_{i,j,h}`$，同时保留 $`A_{0,0}=1`$。随后按长度 $`d=B-1,B-2,\ldots,1`$ 加入短段。一次加入当前长度的段，对应完全背包转移：

```math
A_{i,h}\gets A_{i,h}
+[i\gt1]A_{i-1,h}
+[h\ge d]A_{i-1,h-d}.
```

这里 $`i`$ 必须递增，让同一个长度可以出现任意多次；高度也递增即可。第一段必须标记的限制，在两种 DP 中都由禁止 $`i=1`$ 的“不贡献”转移保证。

## 正确性证明

长段 DP 按当前最短长度是否为 $`B`$ 唯一划分方案。删去末段或整体减一都可逆，因此没有遗漏和重复。第一段标记限制、贡献段数和高度在转移中都被准确维护。

长段处理完成后，非增序列的短段必然按长度从大到小接在末尾。每个新位置有且仅有贡献与不贡献两种锁定方式，完全背包正好枚举这两种选择。逐个加入所有短长度后，$`A_{n,m}`$ 就覆盖全部合法梯子。

## 复杂度与实现要点

预处理时间为 $`O(NM(B+M/B))=O(NM\sqrt M)`$；空间为 $`O(NM+M^2/B)`$。每次询问 $`O(1)`$。代码滚动长段 DP，并保存二维答案表，避免保留完整三维数组。

- 三个模数以内的和使用无符号 32 位整数，随后至多减模两次。
- 空序列仅作转移初值；不能对空序列做“整体加一”。
- 官方最大样例：$`n=m=2000`$，答案为 `204576309`。

## 补题切入点

先独立写出 $`O(nm^2)`$ 的按长度 DP 和 $`O(nm\min(n,m))`$ 的按贡献段数 DP，再寻找“段长大则贡献段数少”的互补关系。这题训练的是把两种慢算法拼成根号复杂度。
