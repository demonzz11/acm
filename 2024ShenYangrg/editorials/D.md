# D · Dot Product Game：点积博弈

[返回题单](../README.md) · [C++17 实现](../solutions/D.cpp) · [官方题面，第 7–8 页](https://ucup.ac/statements/statements-3-19.pdf#page=7) · [官方题解，第 9–11 页](https://ucup.ac/tutorials/tutorials-3-19-zh.pdf#page=9)

## 题意与约束

给定两个 $`1\ldots n`$ 的排列 $`A,B`$。Alice 先手，只能交换 $`A`$ 的两个元素；Bob 只能交换 $`B`$ 的两个元素。交换后点积必须严格增大，不能操作者输。

另有 $`n-1`$ 次修改，每次将某个排列的 $`[l,r]`$ 循环左移 $`d`$ 次。输出初始及每次修改后的赢家，共 $`n`$ 个字符。所有测试的 $`n`$ 之和不超过 $`5\cdot10^5`$。

## 将两个排列合成一个相对排列

交换位置 $`i,j`$ 后，点积变化为：

```math
\Delta=(a_i-a_j)(b_j-b_i).
```

所以可交换当且仅当两组数的大小关系相反。按 $`A`$ 的值排序位置，定义 $`P_{a_i}=b_i`$。合法操作就是交换相对排列中的一对逆序元素。

这样的交换会严格减少逆序数，并且改变逆序数的奇偶性。对于逆序对 $`P_x\gt P_y`$，$`x\lt y`$，逆序数减少：

```math
1+2\left|\{k:x\lt k\lt y,\ P_y\lt P_k\lt P_x\}\right|.
```

因此游戏一定结束，而且仅当相对排列没有逆序对，也就是恒等排列时结束。每条合法游戏路径的步数奇偶性相同：等于初始逆序数的奇偶性。奇数步 Alice 赢，偶数步 Bob 赢，双方如何选择操作都不会改变赢家。

## 线性求奇偶性，常数维护修改

排列的符号满足复合乘法，因此：

```math
\mathrm{parity}(P)
=\mathrm{parity}(A)\mathbin{\oplus}\mathrm{parity}(B).
```

一个长度为 $`n`$、有 $`c`$ 个置换环的排列，其奇偶性为 $`(n-c)\bmod2`$。分别遍历两个排列的环即可在线性时间求初值。

长度为 $`r-l+1`$ 的循环左移一次，相当于 $`r-l`$ 次交换。于是修改只需：

```math
p\gets p\mathbin{\oplus}\bigl((r-l)d\bmod2\bigr).
```

无需实际移动数组，也无需关心修改的是哪个排列。

## 复杂度与复盘

每组时间 $`O(n)`$，空间 $`O(n)`$。实现用两个因子的最低位求乘积奇偶，避免无意义的大数乘法。$`n=1`$ 时没有合法操作，输出 `B`。

你原来的 [D.cpp](../D.cpp) 用树状数组统计两份逆序数，结论相同，时间 $`O(n\log n)`$；参考实现换成置换环求符号。补题时应重点掌握“所有终局路径的长度奇偶相同”的证明，而不是只记最后的异或式。
