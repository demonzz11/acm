# F · Light Up the Hypercube：点亮超立方体

[返回题单](../README.md) · [C++17 实现](../solutions/F.cpp) · [官方题面，第 11–12 页](https://ucup.ac/statements/statements-3-19.pdf#page=11) · [官方题解，第 30–35 页](https://ucup.ac/tutorials/tutorials-3-19-zh.pdf#page=30)

## 题意与约束

$`n`$ 维超立方体有 $`2^n`$ 个顶点，每个顶点有一盏灯。操作类型 $`i`$ 可以翻转一个沿 $`i`$ 的二进制一位对应维度展开的子立方体，其余维度的固定坐标任选，费用为 $`a_i`$。

初态可能是全部 $`2^{2^n}`$ 种状态中的任一种。求操作序列最小费用，使每种初态都在某次操作后全亮；初始状态不计。$`2\le n\le20`$，$`1\le a_i\le10^6`$，所有测试的 $`2^n`$ 之和不超过 $`2^{20}`$，答案对 $`998244353`$ 取模。

## 状态图是异或群的 Cayley 图

令 $`r=2^n`$，每次具体操作对应 $`r`$ 位的非零向量。累计翻转向量必须在**正时间**覆盖全部 $`2^r`$ 种值，包括零。因此要求从零出发、正时间遍历所有顶点的最短游走。

设状态图最小生成树权值为 $`W`$，最便宜操作费用为 $`c_1`$。答案为：

```math
W+c_1.
```

下界：游走必须至少执行 $`2^r`$ 步，因为出发时不计一次访问，并且必然回到零形成回路。从游走多重图的回路中删去一条边后仍连通，剩余费用至少为 $`W`$，被删边至少为 $`c_1`$。

上界：按费用贪心取一个由实际操作组成的线性基，权值依次为 $`c_1\le\cdots\le c_r`$。先执行第一个基向量，再从当前点开始走平移后的二进制格雷码路径，最低位对应最便宜基向量。该路径在正时间恰好访问全部状态。各基向量使用次数给出费用：

```math
c_1+\sum_{i=1}^{r} c_i2^{r-i}.
```

Kruskal 在加入第 $`i`$ 个独立基向量时，连通分量数由 $`2^{r-i+1}`$ 降至 $`2^{r-i}`$，需 $`2^{r-i}`$ 条权为 $`c_i`$ 的边。所以求和部分正好是 $`W`$。

## 不显式维护巨大线性基

把超立方体顶点也用子集编号。类型 $`i`$ 的一个面，其最大顶点编号为某个超集 $`j\supseteq i`$。可以证明，在所有已启用操作形成的线性空间中，基的维数等于被这些类型的超集覆盖的顶点数。

更具体地，取基向量 $`z_j`$ 为“编号是 $`j`$ 子集的所有顶点”的指示向量。类型 $`i`$、固定坐标为 $`S`$ 的面可写成：

```math
\bigoplus_{T\subseteq S}z_{i\cup T}.
```

这是一个可逆的三角变换。因此同一类型的全部平移面恰好张成 $`j\supseteq i`$ 的这些基坐标；多个类型合并时，对应坐标取并集。

于是顶点基坐标 $`j`$ 被启用的最低费用为：

```math
b_j=\min_{i\subseteq j}a_i.
```

用 SOS DP 求全部 $`b_j`$，将它们升序排序，得到上面的 $`c_1,\ldots,c_r`$，再从后往前维护二的幂求和。虽然真实最小费用极其巨大，比较时只用原始小整数，**仅最终累加取模**。

## 复杂度与易错点

SOS DP 和排序的总时间均为 $`O(n2^n)`$，空间 $`O(2^n)`$。

- 不能漏掉额外的最便宜操作：零累计翻转也必须在某次操作后访问。
- SOS 的方向是子集最小值，不能做成超集最小值。
- 当所有费用均为一，答案为 $`2^{2^n}\bmod998244353`$。

## 补题切入点

先补 E，感受“覆盖所有初态等价于访问累计翻转状态”。再复习线性基、Kruskal 的连通分量计数、格雷码和 SOS DP。代码很短，证明才是本题的主要难点。
