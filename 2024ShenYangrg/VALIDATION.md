## 独立校验方法

| 题目 | 检查数 | 与参考算法不同的校验方式 |
| --- | ---: | --- |
| A | 48 | 枚举非增长度序列及每个位置的锁定方式，直接计算高度；最大样例另查 |
| B | 1,225 | 对所有小矩阵逐格算乘积、检查参数范围和颜色唯一性，覆盖单行、单列与一格 |
| C | 3,136 | 按原规则记录每格残留陨石和角色位置，枚举清理子集与自由连通段内的移动；含三格三轮二进制落石穷举 |
| D | 1,200 | 对两份排列和当前回合做精确博弈搜索，修改时真的执行区间旋转，不使用奇偶公式 |
| E | 225 | 正向 Dijkstra，状态为累计翻转与已满足初态集合，独立检查不同费用和初始全亮 |
| F | 30 | 显式建立二维、三维的完整灯状态图做 Prim；再用实际面向量的线性基构造正时间格雷码游走，验证下界可达 |
| G | 75 | 实际子进程交互；用有理数截面计算器回答询问，再用鞋带公式核对最终面积与询问限制 |
| H | 90 | 枚举所有包含风景边的地图，逐张按编号做真实 DFS，检查经过的特殊边与非特殊边 |
| I | 504 | 枚举被修改边集合、直接匹配可用日期，并检查所有叶子的原路径和及修改边集合；树高一至四 |
| J | 24 | 直接模拟三轮淘汰赛，不使用半区最大值公式 |
| K | 14 | 官方数值样例外，检查直径、单调性、路程上界、随机物理射线下界，以及平移旋转倍缩放关系 |
| L | 5,000 | 在小时间范围枚举全部整数删除区间，重新按原始提交规则计分与排名，检查最短长度及最小左端 |
| M | 180 | 枚举余数图的有向简单环检查非零权值，再用传递闭包检查可达性，不使用 SCC 势能判定 |

F 的显式 Prim 检查最小生成树下界，实际操作游走检查该下界加最便宜边能达到；不是直接再次运行 SOS 公式。G 的多边形顺序只保存在交互器里，被测程序接收乱序点。

K 的随机射线只能提供可行下界，不能单独证明最优性；上限与变换关系属于额外一致性检查。最优值正确性还依赖题解中的展开与候选点对证明，数值极端情况仍需要在线评测进一步检验。
